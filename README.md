# DiSH-Bench ICLR demo

This public static package contains 15 task views, seven curated Foundation samples linked to frozen English 2k + 2k dev datasets, and eight explicitly marked protocol-only extension pages. It publishes selected FOA audio and corresponding GT only; the formal test split, private gold archives, model predictions, and legacy Xiaochi/小驰 assets are excluded.

Published at: https://wenanzhi.github.io/dish-bench-demo/
